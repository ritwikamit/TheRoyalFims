# The Royal Films

Cinematic video production and luxury event media portfolio web application.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set the `GEMINI_API_KEY` in `.env.local` if using AI features
3. Run the development server:
   ```bash
   npm run dev
   ```
